# データ精度メモ

## 現在の位置づけ

このプロジェクトの現段階は、山手線形成史を地図と時間軸で見せるための概念デモです。

厳密な鉄道史データベースではなく、次の体験を検証することを優先しています。

- 1885 年の品川線から始まる形成過程を地図上で追える
- 2 年刻みのスライダーで路線の増え方が分かる
- 「しの字」「C の字」「のの字」「環状線」という変化が直感的に伝わる

## 現時点で正確ではないもの

- 当時の正確な線形
- 全駅・全区間の網羅
- 建設開始年・計画開始年の厳密な定義
- 貨物線、支線、運転系統の細かい差異
- 駅位置や経路の歴史的な移設差分
- 山手線以外の関東 JR 主要路線の `openedYear` は、現時点では全区間の厳密な開業年ではなく、MVP 表示上の代表年

## 現在の地図データ方針

- 駅位置は現在地図上の概略座標を使う。
- 路線は `geoLine` の概略ラインで表示する。
- 当時の線形再現ではなく、形成過程の理解を優先する。
- 将来的に検証済み GeoJSON を追加する場合は、`geojsonFile` に分離する。

## 次に精度を上げる候補

- 1885 年開業時の品川線の駅・区間を資料ベースで再確認する。
- 1903 年の豊島線区間を整理する。
- 1909 年の山手線統合と電車運転開始の扱いを明確にする。
- 1919 年の「の」の字運転と中央本線接続の表現を見直す。
- 1925 年の環状運転開始時点の区間を GeoJSON 化する。
- 関東 JR 主要路線 v1 の `needs-verification` を路線ごとに検証する。
