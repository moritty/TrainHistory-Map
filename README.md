# TrainHistory-Map

## 目的

日本の鉄道路線が、どのように計画され、どれくらいの期間をかけて建設され、いつ開業・廃止されていったのかを、地図とタイムラインで可視化する Web アプリです。

Google マップのような地図 UI に時系列スライダーを組み合わせ、選択した年時点の路線状態を「計画中」「建設中」「開業済み」「廃止済み」などで色分けして表示します。

単なる鉄道路線図ではなく、都市と交通インフラが時間をかけてどう形成されたかを見るための歴史・地理・都市開発ビジュアライザーを目指します。

## 作成背景

鉄道路線の発展は、駅周辺開発、都市化、人口増加、大規模施設の開業、行政区画の変化などと密接に関係しています。このプロジェクトでは、鉄道史と都市史を同じ地図・年表上で扱い、路線網が成長していく過程を直感的に追える体験を作ります。

将来的には、日本の歴史で新橋に汽車が走り始めた時代から現代まで、鉄道がどのように伸び、増えていったかを動画のように見られる体験を目指します。

## MVP 方針

最初から全国全路線を扱うのではなく、山手線をテーマにした概念デモから始めます。

MVP の基本方針:

- テーマ: 山手線
- 起点: 1885 年 3 月 1 日に日本鉄道品川線として開業した品川〜赤羽間
- 地図: 淡色の通常地図
- 時間軸: 2 年刻みスライダー
- 体験: Google マップのような地図操作に、時間経過で変化する鉄道路線・駅・イベントを重ねる
- 操作 UI: タイムライン操作は常に画面下部に表示する
- 対応画面: MVP ではスマホでも操作できるレイアウトを用意する

最初のストーリーは、現在の環状線として完成した山手線ではなく、品川〜渋谷〜新宿〜赤羽を結ぶ非環状の路線から始めます。その後、池袋・田端方面への接続、上野・東京方面との連絡、1925 年の環状運転開始へ進む流れを見せます。

MVP で扱う主な機能:

- 地図表示
- 年代スライダー
- 路線の状態別色分け
- 路線クリックによる詳細表示
- 駅マーカー表示
- 選択年に応じたイベント年表表示
- 静的 JSON / GeoJSON による最小データ管理

MVP の主要年表は [docs/yamanote_mvp_timeline.md](./docs/yamanote_mvp_timeline.md) に記録します。

データ項目の方針は [docs/data_model.md](./docs/data_model.md) に記録します。

TODO と保留事項は [docs/todo.md](./docs/todo.md) に記録します。

データ精度と現時点の制約は [docs/data_accuracy.md](./docs/data_accuracy.md) に記録します。

関東 JR 主要路線の追加方針は [docs/kanto_jr_major_lines_v1.md](./docs/kanto_jr_major_lines_v1.md) に記録します。

東京都内の私鉄開業史 21 件の入力データは `input/` に受領し、アプリ表示用には `public/data/railway_openings.json` と `data/railway_openings.json` に配置します。

## MVP 達成内容

2026-05-16 時点で、山手線形成史 MVP として以下を達成しています。

- PC で地図を表示できる
- スマホで地図を表示できる
- スマホで再生ボタンとタイムバーを常時表示できる
- 1870 年から 2025 年までを 2 年刻みで操作できる
- 再生ボタンで時間経過を自動表示できる
- 山手線が最初から環状線ではなく、段階的に形成されたことが伝わる
- 「しの字」「C の字」「のの字」「環状線」の段階を表示できる
- 路線、駅、イベントを JSON データから読み込んで表示できる
- データ精度に関する注記を画面とドキュメントに用意している
- Next.js + TypeScript + Leaflet の構成で動作する
- `npm run typecheck` と `npm run build` が通る

2026-05-18 時点で、表示バージョンを `v0.2.0` として追加しています。PC では右上、スマホでは地図右上のオーバーレイに表示します。

## 次フェーズ: データ精度の強化

データ精度の強化とは、現在の「概念デモ用の仮データ」を、資料に基づいた説明・年表・地図データへ近づける作業です。

具体的には以下を行います。

- 1885 年の品川線開業時の駅・区間を資料ベースで確認する
- 1903 年の豊島線の扱いを確認する
- 1909 年の山手線統合・電車運転開始の説明を整理する
- 1919 年の「の」の字運転の意味と表示方法を見直す
- 1925 年の環状運転開始時点の区間を確認する
- 現在地図上の概略線ではなく、検証済みの GeoJSON 線形を用意する
- 各イベントに参照元や補足説明を追加する
- 「計画開始年」「建設開始年」が曖昧な箇所は、不明または推定として明示する

2026-05-17 時点では、山手線以外の関東 JR 主要 10 路線を概略表示 v1 として追加しています。これらは `needs-verification` 扱いで、今後の精査対象です。

同日、東京都内の私鉄開業史 21 件を追加しました。1902 年以降、東武・京急・玉電・京成・京王・東武東上・西武池袋・西武新宿・東急系の初期区間が、選択年に応じて表示されます。現時点では `approxCoordinates` による概略線で、後から `public/data/geojson/*.geojson` の検証済み線形へ差し替える前提です。

MVP では扱わないもの:

- 全国全路線対応
- 完全な鉄道史データベース
- 乗換案内
- 現在のリアルタイム運行情報
- ユーザー投稿機能

## 技術スタック

候補:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Leaflet
- MapLibre GL JS
- 静的 JSON / GeoJSON

現在のアプリは Next.js + TypeScript 上で Leaflet を使い、国土地理院の淡色地図タイルを背景にしています。将来的に MapLibre GL JS への移行も検討します。

初期データは `public/data` 配下で管理します。ルート直下の `data` は、初期の静的サンプルから残している元データです。

```text
public/data/
  railway_segments.json
  railway_openings.json
  stations.json
  events.json
  year_summaries.json
```

## セットアップ

```bash
npm install
```

## 実行方法

開発サーバーを起動します。

```bash
npm run dev
```

起動後、ブラウザで以下を開きます。

```text
http://localhost:3000/
```

スマホで確認する場合は、PC とスマホを同じ Wi-Fi に接続し、`npm run dev` の起動ログに表示される `Network` の URL をスマホで開きます。

例:

```text
http://192.168.x.x:3000/
```

スマホでは `localhost` ではなく、PC 側のネットワーク IP アドレスを使います。
