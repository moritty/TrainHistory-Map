# 東京都内 私鉄開業順データ 初期案

## 目的

東京都内における私鉄・民営鉄道系の開業履歴を、時系列地図アプリに表示するための初期データとして整備する。

## 対象範囲

### 含めるもの

- 東京都内に起点または区間を持つ私鉄
- 現在の大手私鉄につながる路線
- 廃止済みでも、現在の鉄道網・都市形成に影響が大きい路線
- 東急・京王・京成・東武・西武・京急系の初期区間
- 路面電車的な性格を持つが、現在の私鉄史に重要なもの

### 除外するもの

- JR・旧国鉄・旧日本鉄道系
- 都電・都営地下鉄などの公営交通
- 貨物専用線
- 専用鉄道
- すべての馬車鉄道・人車軌道
- 駅単位の細かな開業履歴

## 注意

このリストは、厳密な法的・網羅的な開業順位ではなく、地図アプリのMVPに入れやすいように整理した「主要開業区間リスト」です。

古い私鉄は、停留場単位の開業日、路面電車・軌道線・鉄道線の扱い、駅名変更、廃止・移設・会社合併などにより情報が揺れやすいため、実装時は `sourceStatus` と `needsVerification` を持たせます。

## 表示ステータス案

type RailwayStatus =
  | "not_yet"
  | "planned"
  | "under_construction"
  | "opened"
  | "closed"

## 実装上の補足

MVPでは、正確な線形データを最初から作らなくてよいです。

1. 各路線に代表的な始点・終点の緯度経度を仮設定する
2. 直線のLineStringとして地図に出す
3. UIとタイムラインの動作を確認する
4. 後から正確なGeoJSONに差し替える

この順番にすると、データ整備に時間を取られすぎず、まず「年を動かすと東京の私鉄網が増えていく」という体験を確認できます。
